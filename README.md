# まなび時刻表

勉強の「今日やること」と通学の時刻表をひとつにまとめた、スマホでもPCでも使えるWebアプリです。

- **今日やること**：単元チェックと連動。単元ごとの「やること」（読む節・解く例題）を予定日ごとに表示し、チェックすると単元の進み具合に反映されます。予定日を過ぎた分は「持ち越し」に出ます。
- **単元チェック**：科目ごとの単元と進み具合。教科書の目次を貼り付けてまとめて登録できます。
- **通学の経路**：自分の時刻表データから、乗り換え時間（時間帯ごとの設定も可）を考えた経路を計算します。「今日」画面には、決めた時刻までは行き・それ以降は帰りの次の電車を自動で表示します。
- **学内バスなど**：運行日カレンダーつきの時刻表を表示します。
- **勉強タイマー**：ストップウォッチとポモドーロ。単元ごと・日ごとの勉強時間を記録します。
- **学習計画（任意）**：日ごとの使える時間に合わせて、やり残した分を自動で後日に振り分けます。理解度（◎○△×）、復習1・2の期限、週ごと・本ごと（目次）の表示、やったページの記録もできます。
- **PCとスマホの同期（任意）**：自分の GitHub の非公開リポジトリを通して、どの端末でも同じ内容にします。

## アプリとして使う

1. GitHub Pages のURL（このリポジトリの About 欄）をスマホで開きます。
2. ホーム画面に追加します。
   - iPhone（Safari）：共有ボタン →「ホーム画面に追加」
   - Android（Chrome）：メニュー →「アプリをインストール」または「ホーム画面に追加」
3. 右上の「データ」から自分のデータファイルを読み込みます。動きを見るだけなら「お試しデータ」を押してください。

一度開けば、電波がないところでも動きます。

## データの扱い

- このアプリには**時刻表も単元も入っていません**。使う人がそれぞれデータファイル（JSON）を用意して読み込みます。
- 読み込んだデータと、チェックや勉強時間の記録は、**その端末のブラウザの中だけ**に保存されます。どこにも送信しません。
- 別の端末に移すときは、「データ」→「バックアップを保存」で書き出したファイルを、移したい端末で読み込みます。
- 自分のデータファイルは公開リポジトリに入れないでください（`private/` フォルダは `.gitignore` 済みです）。

## PCとスマホの同期（GitHub の非公開リポジトリ）

1. GitHub で**非公開**のリポジトリを1つ作ります（中身は空で構いません）。
2. [Fine-grained personal access token](https://github.com/settings/personal-access-tokens/new) を作ります。
   - Repository access：**Only select repositories** でそのリポジトリだけを選ぶ
   - Permissions → Repository permissions → **Contents：Read and write**
3. アプリの「データ」→「PCとスマホの同期」に `ユーザー名/リポジトリ名` とトークンを入れて「接続して同期」。
4. ほかの端末でも同じリポジトリ名とトークンを入れます。

- 同期するのは `state.json`（単元・進み具合・勉強の記録）と `pack.json`（時刻表・学習計画）の2つのファイルです。
- 変更すると数秒後に書き込み、アプリを開いたとき・画面に戻ったとき・1分ごとに読み込みます。オフラインのあいだはその端末に保存し、つながったら同期します。
- 2つの端末で同時に変えた場合は、単元ごとに新しく変えたほうを残します。
- 公開リポジトリは指定できません。トークンはその端末のブラウザの中だけに保存されます。端末をなくしたときやトークンが切れたときは、GitHub でトークンを無効にして作り直してください。
- トークンは同じ `ユーザー名.github.io` で公開している他のページからも読めてしまうので、信頼できないページを同じアカウントで公開しないでください。

## データファイルの形式

`"format": "manabi-data"` を持つ JSON です。`transit`（電車）・`bus`（バス）・`units`（単元）はどれも省略でき、入っているものだけ読み込まれます。具体例は [`sample-data.json`](sample-data.json)（架空のデータ）を見てください。

```jsonc
{
  "format": "manabi-data",
  "version": 1,
  "title": "表示名",
  "transit": { ... },
  "bus": { ... },
  "units": { "subjects": [...], "units": [...], "tasks": [...] }
}
```

### transit（電車）

| キー | 内容 |
|---|---|
| `strings` | 列車種別・行き先の文字列の一覧（下の `legs` から番号で参照） |
| `legs` | 区間ごとの時刻表。`{"区間名": {"wd": [...], "hd": [...]}}`。`wd` は平日、`hd` は土休日ダイヤ。1本の列車を `[発, 着, 種別の番号, 行き先の番号, 始発なら1]` の5つの数で表し、それを並べます。時刻は0時からの分（深夜0時台は 24:10 → 1450 のように1440を足す） |
| `lines` | 路線名と色。`{"id": {"name": "〇〇線", "color": "#2a78d6", "dark": "#3987e5"}}` |
| `transfers` | 乗換。`{"id": {"label": "〇〇乗換", "min": 2, "walk": false, "windows": [{"from": "07:00", "to": "08:00", "min": 4, "label": "朝の時間帯"}]}}`。`windows` は乗換駅に着く時刻が `from` 以上 `to` 未満のときに使う乗換時間 |
| `routes` | 経路。`{"id", "label", "note", "legs": [{"leg": 区間名, "line": 路線id, "from", "to"}], "transfers": [乗換id]}`。区間はいくつでもつなげられます |
| `groups` | 経路のまとまり（例：行き・帰り）。`[{"id": "out", "label": "行き", "routes": [...]}]` |
| `autoSwitch` | 「今日」画面の自動切り替え。`{"before": "out", "after": "back", "at": "14:00"}` |
| `holidays` | 追加の休日（`"YYYY-MM-DD"` の配列）。土日・国民の祝日・12/30〜1/3 は自動で土休日ダイヤになります |
| `source` | 時刻表の出典や注意書き（画面の下に表示） |

### bus（バス）

| キー | 内容 |
|---|---|
| `label` | 表示名 |
| `routes` | `{"id", "label", "short", "sub", "from", "to", "arrLabel", "depStops": [{"label", "offset"}], "trips": "07:45-08:30a 08:30-09:15b ..."}`。`trips` は `発-着` の後ろに便の種類を1文字 |
| `classes` | 便の種類。`{"a": {"label": "1便", "short": "1便", "runs": ["1", "2"]}}`。`runs` はその便が走る日の種類 |
| `dayTypes` | 日の種類の名前。`{"2": "2台運行"}` |
| `calendar` | 日付ごとの日の種類。`{"2": "2026-10:2,5,6|2026-11:6,9"}`（載っていない日は運休） |
| `weekdays` | 曜日ごとの日の種類（`calendar` の代わりに使える）。`{"1": [1,2,3,4,5]}`（0=日曜） |
| `range` / `refType` / `legend` / `source` | 運行期間・期間外に参考表示する日の種類・凡例・出典 |

### units（単元）

- `subjects`: `[{"id", "name", "color": 0〜7}]`
- `units`: `[{"id", "subjectId", "name", "status": "todo|doing|done", "plan": "YYYY-MM-DD", "week", "weekId", "fixed": "11/23（月）", "book", "ref", "refs": [{"t", "bk", "k": [...]}], "est": 分, "level": "◎|○|△|×", "r1At", "r2At", "note", "steps": [...]}]`
- `steps`（やること）: `[{"t": "内容", "b": "本の名前", "bk": "本のキー", "k": ["目次のキー"], "kind": "n（予定に入る）| a（応用・余裕があれば）", "plan": "YYYY-MM-DD", "base": "最初の予定日", "done": "YYYY-MM-DD"}]`
- `booklog`（やったページの記録）: `[{"id": "本のキー", "entries": [{"d": "YYYY-MM-DD", "text": "p.40〜45"}]}]`
- 日付は `"+0"`（読み込んだ日）、`"+1"`（翌日）、`"-1"`（前日）のように相対でも書けます。

### plan（学習計画・任意）

| キー | 内容 |
|---|---|
| `start` / `end` | 計画の開始日と終了日（試験日など。`countdownLabel` と合わせて「試験まで ○日」を表示） |
| `capacity` | 1日に使える時間の比率。`{"weekday": [日,月,火,水,木,金,土の比率], "off": [勉強しない日], "half": [半分の日], "full": [2倍の日]}`。予定日を過ぎた「やること」は、この比率に合わせて近い日に振り分けられます |
| `review` | 復習の期限。`{"subjects": [科目id], "first": 3, "second": 7}`（完了の3日後に復習1、その7日後に復習2） |
| `levels` | 理解度（◎○△×）を付ける科目。`{"subjects": [科目id]}` |
| `weeks` | 週ごとの表示。`[{"id", "n": "第1週", "s": "開始日", "e": "終了日", "h": 目安時間}]` |
| `books` | 本ごとの表示。`[{"k": "キー", "n": "書名", "role": "使い方", "subjectId", "toc": [["目次のキー", "章・節", "ページ", "注記"]]}]` |

## 開発

- 本体は `src/app.html` です。`python3 tools/build.py` で公開用の `index.html` を作ります。
- `python3 dev_server.py` で http://localhost:8080 に開発用サーバーが立ちます。
- `python3 tools/make_sample.py` で `sample-data.json` を作り直します。
- 自分のデータを組み込んだ1ファイル版は `python3 tools/build.py --embed private/my-data.json --out private/manabi.html` で作れます（公開しないでください）。
