    時刻表データがまだありません

    このアプリには時刻表が入っていません。自分の通学経路の時刻表をデータファイルにして読み込むと、乗り換えを含めた経路を計算して表示します。データファイルの作り方はリポジトリの README を見てください。

      乗り換え時間の設定

      乗換時間は「到着してから次の列車が出るまでに必要な最短時間」です。時間帯の設定は、乗換駅に着く時刻が開始以上・終了未満のときに使います。変えた値はこの端末に保存されます。

      00:00
      準備OK
      集中 分 ／ 休憩 分

      終了すると、選んだ単元と今日の勉強時間に記録されます（1分未満は記録しません）。
